# M10 evidence — release hardening and version-one distribution

Date: 2026-07-24

Status: repository and local Windows preflight complete; signed external
candidate gates pending

## Delivered

- Synchronized the package, Cargo, lockfile, and Tauri version at `1.0.0`.
- Added a deterministic release artifact contract for the exact official
  installer, Tauri signature, update metadata, Authenticode evidence,
  checksums, SPDX SBOM, dependency-license report, and notices.
- Added immutable-action Windows CI and a protected GitHub release workflow
  that Authenticode-signs the main executable, one-shot helper, and installer
  before Tauri-signing the final installer bytes.
- Added GitHub provenance attestation and fail-closed official-origin metadata
  generation.
- Added a reviewed Windows production dependency-license policy and recorded
  npm/RustSec audit results.
- Branded the per-user NSIS installer/uninstaller and constrained production
  Cargo builds to the main executable. The helper and developer tools require
  separate explicit features.
- Added complete install, development, contribution, security, privacy,
  troubleshooting, Stable/Beta release, notices, and version-one release-note
  documentation.
- Added automated WCAG AA contrast contracts for semantic text/filled actions
  while retaining the approved base UI tokens, plus explicit focus and
  reduced-motion contracts.
- Corrected Tauri updater initialization so unsigned development builds start
  with no trust root or endpoints and continue to fail closed.

The local unsigned NSIS preflight installed version `1.0.0` for the current
user and produced exactly:

- `formation-lap.exe`;
- `formation-lap-elevated-helper.exe`; and
- `uninstall.exe`.

The installed native app exposed a responsive Windows window and exited cleanly
with code 0 when its idle window closed. Silent uninstall removed the
application directory, registry registration, and Start Menu shortcut while
preserving the per-user configuration directory.

## Remaining external evidence

M10 is not complete and no public release or tag has been created. Completion
requires:

1. protected GitHub `release` environment reviewers and updater/Azure signing
   configuration;
2. one signed Beta workflow run with signature, checksum, SBOM, license,
   provenance, and updater verification;
3. install/launch/update/uninstall and accessibility qualification on clean
   Windows 10 22H2 and Windows 11 systems; and
4. approval to create the Stable `v1.0.0` tag only after the Beta matrix is
   complete.
