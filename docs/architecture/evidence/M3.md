# M3 evidence — Local application lifecycle

Status: `in_progress`

## Core lifecycle tracer

FormationLapCore now owns the first application lifecycle transition behind the
approved ProcessRuntime seam:

- a configured direct executable with no matching Process becomes `Starting`;
- its PID, creation time, and canonical executable path are retained as one
  stable identity;
- the Process is marked `SessionOwned`;
- a matching Process becomes `RunningPreExisting`;
- a Pre-existing Process is observed without taking Session ownership or
  launching a duplicate;
- React-facing state is generated from the authoritative Rust contracts.
