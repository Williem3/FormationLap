# M5 evidence - Curated catalog and local discovery

Status: `in_progress`

## Current slice

FormationLapCore now opens the versioned bundled Curated Catalog and returns
exactly the accepted version-one set:

- ten Primary Sims;
- nine Supporting Applications;
- reviewed Steam App IDs for each Steam Primary Sim.

The Curated Catalog remains immutable bundled application content under
[`catalog/`](../../../catalog). No remote catalog path exists.

FormationLapCore also accepts explicit targeted discovery roots. Steam
discovery reads only:

- the configured Steam root;
- that root's `steamapps/libraryfolders.vdf`;
- `appmanifest_<id>.acf` files for Curated Catalog App IDs; and
- the declared installation directory for each matching manifest.

It does not enumerate unrelated directories or scan a drive. An installation
is returned only when its declared directory exists.

returns the two verified installations in catalog order and omits the stale
entry.
