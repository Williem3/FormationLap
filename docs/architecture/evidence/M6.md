# M6 evidence — Steam, non-Steam, and VR launch recipes

Date: 2026-07-24

## Outcome

Formation Lap resolves a Racing Profile's Primary Sim to an explicit Steam
launch option or a direct executable. The Dashboard remembers the VR toggle,
locks it outside Idle, and exposes Test Game Launch without starting Supporting
Applications. The command records a sanitized local diagnostic and learns the
observed executable name as a per-profile override without changing the bundled
Curated Catalog.

Steam dispatch uses `ShellExecuteW` with one validated `steam://` URI; direct
launch continues to canonicalize the executable and pass arguments directly.
Neither adapter constructs a shell command string.

FormationLapCore and observes the typed recipe received by ProcessRuntime.
`Default`, `OpenVR`, `Oculus`, and `Option N` are explicit launch-option
selectors; none is Steam's `Dialog` launch type.

The validator also rejects a Steam sim without recipes, a monitored path rather
than an executable filename, and duplicate VR modes. FormationLapCore rejects a
VR mode the selected curated sim does not declare, while preserving an explicit
per-profile selector, arguments, and monitored-process override.

Valve documents that launch options select non-VR, OpenVR, Oculus, and numbered
modes, with `Dialog` as a separate type:

- [Valve Steamworks VR launch settings](https://partner.steamgames.com/doc/features/steamvr/settings?l=english)
- [Valve `ELaunchOptionType` definitions](https://partner.steamgames.com/doc/api/steam_api?l=english)

Game-specific behavior with a non-Steam mode selector is retained where the
game owns the selection:

- [iRacing graphics device selection](https://support.iracing.com/support/solutions/articles/31000164651-sim-graphics-device-selection)
- [Le Mans Ultimate VR launch guidance](https://guide.lemansultimate.com/hc/en-gb/articles/13240709086607-How-to-play-in-Virtual-Reality-VR)
- [Le Mans Ultimate v1.4 native OpenXR release notes](https://guide.lemansultimate.com/hc/en-gb/articles/16987981296015-V1-4-release-notes)
- [Le Mans Ultimate v1.4 OpenXR `+XR` compatibility hotfix](https://guide.lemansultimate.com/hc/en-gb/articles/17030344145935-V1-4-0-2-Update-V1-4-Hotfix-2)

When a Le Mans Ultimate Racing Profile has no saved preferred VR Launch Mode,
the Curated Catalog now defaults VR to its native OpenXR Steam option. An
explicitly saved OpenVR/SteamVR preference remains available as a fallback.

## Test Game Launch diagnostic

The durable example is
[`m6-test-game-launch.json`](m6-test-game-launch.json). It contains the chosen
URI or direct executable filename, structured arguments, and the observed
executable filename. It deliberately omits canonical paths, working
directories, PIDs, environment variables, and other unrelated local data.

The command:

- remains available only while the Session is Idle;
- resolves and starts or adopts only the Primary Sim;
- writes `logs/test-game-launch.json` atomically with a local backup;
- leaves the Session Idle;
- records the observed executable filename in the Racing Profile when no
  per-profile monitored-process override exists; and
- proves the bundled `catalog/sims.json` bytes are unchanged.

The Dashboard renders the sanitized result and a read-only copyable JSON field.

## Manual verification notes

This maintainer machine has no registered Steam installation, no Steam
executable, and no default standalone iRacing executable. No supported sim was
therefore available for a real game launch. The absence was checked on
2026-07-24 through the targeted Steam registry location and the default iRacing
installation path; an iRacing Documents directory alone was not treated as an
installation.

The available Windows paths were checked as follows:

- The real direct-executable adapter passed eleven Windows fixture cases,
  including structured arguments, monitored launcher identity, windowed and
  console shutdown, stable Process identity, and shell-like text remaining
  inert data.
- Standalone iRacing passed through FormationLapCore without a Steam source.
- The Windows Steam adapter and `ShellExecuteW` path compiled for all targets
  and features. Actual protocol dispatch was not attempted because Steam and
  the supported games are absent.
- The table-driven core suite covers every curated ordinary and VR recipe,
  including the games not installed on this machine.
