# Formation Lap 0.9.0-preview.11 — unsigned technical preview

Formation Lap 0.9.0-preview.11 is an unsigned technical preview for early
evaluation. The application, one-shot elevated helper, and installer do not
carry Windows Authenticode publisher signatures, so Windows may show
SmartScreen and Unknown publisher warnings; this is not a Stable Formation Lap
release.

This preview supersedes 0.9.0-preview.10 with release-readiness security and
data-recovery fixes. Existing preview users should install this version before
testing elevated applications, profile approval, destructive process actions,
or recovery from damaged local state.

## Security and reliability fixes

- Bind explicit privileged-profile approval to the exact SHA-256 bytes of every
  elevated launch and custom-stop executable.
- Hold a verified executable handle that denies write/delete replacement through
  elevated process creation, closing the validation-to-launch substitution
  window.
- Quarantine new privileged profiles and every unsafe, missing, noncanonical,
  forged-approved, or repair-needed launch recipe before Session start.
- Replace renderer force-confirmation booleans with Core-owned, one-shot tokens
  bound to the exact action and stable Process identity.
- Recover corrupt settings and active-Session journals only from a compatible,
  validated backup while retaining bounded copies of the corrupt bytes.
- Synchronize helper protocol v3 across runtime and release identity, and
  strengthen official signed-release credential and signer-equality gates.
- Restrict executable selection to a native, zero-payload `.exe` picker.

## Install

Download `Formation-Lap_0.9.0-preview.11_x64-setup.exe`, `SHA256SUMS.txt`,
`UNSIGNED-PREVIEW.txt`, and the provenance evidence from the official GitHub
prerelease. Verify the installer checksum and provenance before running it.
Expect Windows SmartScreen and UAC to identify the application and elevated
helper as an unknown publisher.

This is a per-user installer for 64-bit Windows 10 22H2 and Windows 11.
Organization policy may block installation or elevation of unsigned software.

## Trust and privacy

The installer has no Authenticode publisher signature. Its update bundle is
still signed with Formation Lap's Tauri updater key and is published with
checksums, an SPDX SBOM, dependency licenses/notices, and GitHub build
provenance. Profiles, settings, discovery results, logs, and recovery state
stay local.
