# Formation Lap 0.9.0-preview.12 — unsigned technical preview

Formation Lap 0.9.0-preview.12 is an unsigned technical preview for early
evaluation. The application, one-shot elevated helper, and installer do not
carry Windows Authenticode publisher signatures, so Windows may show
SmartScreen and Unknown publisher warnings; this is not a Stable Formation Lap
release.

This preview supersedes 0.9.0-preview.11 with native OpenXR launch support for
Le Mans Ultimate v1.4. Existing preview users who race in VR should install
this version and select OpenXR in their Le Mans Ultimate Racing Profile.

## Le Mans Ultimate VR fix

- Add Le Mans Ultimate's first-party OpenXR launch route through Steam option 3
  (`+XR`).
- Use native OpenXR as the curated VR default when the Racing Profile has no
  saved preferred VR Launch Mode.
- Keep OpenVR/SteamVR available as an explicit fallback for users who still
  require it.
- Restore OpenXR to the Racing Profile editor and validate that every curated
  default VR mode has a matching no-dialog Steam recipe.

## Install

Download `Formation-Lap_0.9.0-preview.12_x64-setup.exe`, `SHA256SUMS.txt`,
`UNSIGNED-PREVIEW.txt`, and the provenance evidence from the official GitHub
prerelease. Verify the installer checksum and provenance before running it.
Expect Windows SmartScreen and UAC to identify the application and elevated
helper as an unknown publisher.

This is a per-user installer for 64-bit Windows 10 22H2 and Windows 11.
Organization policy may block installation or elevation of unsigned software.

## Trust and privacy

The installer has no Authenticode publisher signature. Its update bundle is
still signed with Formation Lap's Tauri updater key and is published with
checksums, an SPDX SBOM, dependency licenses/notices, and GitHub build
provenance. Profiles, settings, discovery results, logs, and recovery state
stay local.
