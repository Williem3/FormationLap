# Formation Lap 0.9.0-preview.4 — unsigned technical preview

Formation Lap 0.9.0-preview.4 is an unsigned technical preview for early
evaluation. The application, one-shot elevated helper, and installer do not
carry Windows Authenticode publisher signatures, so Windows may show
SmartScreen and Unknown publisher warnings; this is not a Stable Formation Lap
release.

This preview fixes forward from the unpublished `0.9.0-preview.3` candidate.
That candidate's protected workflow stopped before signing or publication when
its release identity resource was required one step before generation. No
`.3` release assets were published.

## Highlights

- Build the final application and helper with the release-bundle configuration
  while using a fail-closed bootstrap resource that is removed before the real
  signed release identity is sealed.
- Launch elevated applications from the installed preview with a release
  identity bound to the exact main and helper executable bytes.
- Persist explicit elevated and custom-stop Launch Recipe approvals in a
  DPAPI-protected record bound to the exact Racing Profile configuration.
- Return privileged profiles to Needs Review when their protected approval is
  missing, invalid, or no longer matches the reviewed configuration.
- Show locally resolved Primary Sim and Supporting Application icons throughout
  the sidebar, profile wizard, editor, and Dashboard while retaining the
  generic fallback.
- Reorder Supporting Applications directly in the profile editor with
  accessible drag handles, keyboard controls, clear insertion feedback, and
  stable fast-drag cleanup.
- Retain the atomic Racing Profile creation and same-executable companion
  tracking fixes delivered in `0.9.0-preview.2`.

## Install

Download `Formation-Lap_0.9.0-preview.4_x64-setup.exe`,
`SHA256SUMS.txt`, `UNSIGNED-PREVIEW.txt`, and the provenance evidence from the
official GitHub prerelease. Verify the installer checksum and provenance before
running it. Expect Windows SmartScreen and UAC to identify the application and
elevated helper as an unknown publisher.

This is a per-user installer for 64-bit Windows 10 22H2 and Windows 11.
Organization policy may block installation or elevation of unsigned software.

## Trust and privacy

The installer has no Authenticode publisher signature. Its update bundle is
still signed with Formation Lap's Tauri updater key and is published with
checksums, an SPDX SBOM, dependency licenses/notices, and GitHub build
provenance. Profiles, settings, discovery results, logs, and recovery state
stay local. Formation Lap has no account, cloud sync, analytics, or telemetry.
