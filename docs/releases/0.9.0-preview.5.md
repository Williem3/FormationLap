# Formation Lap 0.9.0-preview.5 — unsigned technical preview

Formation Lap 0.9.0-preview.5 is an unsigned technical preview for early
evaluation. The application, one-shot elevated helper, and installer do not
carry Windows Authenticode publisher signatures, so Windows may show
SmartScreen and Unknown publisher warnings; this is not a Stable Formation Lap
release.

This preview fixes the first-party update installation path shipped in earlier
previews. Those builds can discover and verify a newer release, but their
write-capable staging handle prevents Windows from opening the downloaded
installer. Install this `.5` preview manually once; later signed in-app updates
can then use the corrected path.

## Highlights

- Reopen the downloaded Formation Lap installer under a byte-reverified,
  read-only handle before launch, allowing Windows to execute it while
  preventing replacement of the verified path.
- Put the manual `Install update` action beside Check now in Settings.
- Reserve the Dashboard update banner for enabled automatic checks.
- Show the native reason beneath an Unknown Formation Lap update status,
  including the expected missing-public-key explanation in local development
  builds.
- Preserve the exact native updater failure and recovery guidance instead of
  replacing it with a generic Session error.
- Retain the release-identity, protected privileged-profile approval, local
  application icon, profile-creation, and process-observation fixes delivered
  in earlier previews.

## Install

Download `Formation-Lap_0.9.0-preview.5_x64-setup.exe`,
`SHA256SUMS.txt`, `UNSIGNED-PREVIEW.txt`, and the provenance evidence from the
official GitHub prerelease. Verify the installer checksum and provenance before
running it. Expect Windows SmartScreen and UAC to identify the application and
elevated helper as an unknown publisher.

Existing preview users must run this installer manually because the updater
launch defect is in the already-installed executable. The installer preserves
local Formation Lap settings and Racing Profiles.

This is a per-user installer for 64-bit Windows 10 22H2 and Windows 11.
Organization policy may block installation or elevation of unsigned software.

## Trust and privacy

The installer has no Authenticode publisher signature. Its update bundle is
still signed with Formation Lap's Tauri updater key and is published with
checksums, an SPDX SBOM, dependency licenses/notices, and GitHub build
provenance. Profiles, settings, discovery results, logs, and recovery state
stay local. Formation Lap has no account, cloud sync, analytics, or telemetry.
