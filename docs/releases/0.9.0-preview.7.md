# Formation Lap 0.9.0-preview.7 — unsigned technical preview

Formation Lap 0.9.0-preview.7 is an unsigned technical preview for early
evaluation. The application, one-shot elevated helper, and installer do not
carry Windows Authenticode publisher signatures, so Windows may show
SmartScreen and Unknown publisher warnings; this is not a Stable Formation Lap
release.

This preview fixes the installed release-identity defect in preview.6. It
seals the main executable hash before Tauri packages the installer and verifies
the exact files installed by that artifact before publication. The Dashboard
also refreshes its authoritative native snapshot if the first launch step
fails, so `Start session` immediately becomes `Cancel startup` instead of
waiting for navigation.

## Highlights

- Verify the installed main executable and elevated-helper SHA-256 values
  against the signed release identity during the release workflow.
- Restore elevated Supporting Application launches, including Virtual Desktop
  Switcher, when the installed bytes match the approved preview identity.
- Refresh the Dashboard after a failed Session command so its action label and
  Formation Rail reflect the actual `Starting` state immediately.
- Retain immediate cancellation cleanup, updater improvements, protected
  privileged-profile approval, local application icons, and process-observation
  fixes delivered in earlier previews.

## Install

Download `Formation-Lap_0.9.0-preview.7_x64-setup.exe`,
`SHA256SUMS.txt`, `UNSIGNED-PREVIEW.txt`, and the provenance evidence from the
official GitHub prerelease. Verify the installer checksum and provenance before
running it. Expect Windows SmartScreen and UAC to identify the application and
elevated helper as an unknown publisher.

Existing preview users must run this installer manually because the privileged
startup defect is in the already-installed executable. The installer preserves
local Formation Lap settings and Racing Profiles.

This is a per-user installer for 64-bit Windows 10 22H2 and Windows 11.
Organization policy may block installation or elevation of unsigned software.

## Trust and privacy

The installer has no Authenticode publisher signature. Its update bundle is
still signed with Formation Lap's Tauri updater key and is published with
checksums, an SPDX SBOM, dependency licenses/notices, and GitHub build
provenance. Profiles, settings, discovery results, logs, and recovery state
stay local. Formation Lap has no account, cloud sync, analytics, or telemetry.
