# Formation Lap 0.9.0-preview.8 — unsigned technical preview

Formation Lap 0.9.0-preview.8 is an unsigned technical preview for early
evaluation. The application, one-shot elevated helper, and installer do not
carry Windows Authenticode publisher signatures, so Windows may show
SmartScreen and Unknown publisher warnings; this is not a Stable Formation Lap
release.

This preview supersedes unpublished preview.7. Its release workflow creates
the destination directory before silently installing the generated NSIS
artifact for release-identity verification. The installer can therefore be
checked against the signed identity before any preview is published.

## Highlights

- Create the temporary NSIS destination before installation, then verify the
  installed main executable and elevated-helper SHA-256 values against the
  signed release identity.
- Retain the preview.7 fix that seals the identity for the exact packaged
  executable bytes, restoring elevated launches such as Virtual Desktop
  Switcher.
- Retain the Dashboard refresh after a failed Session command, so `Start
session` becomes `Cancel startup` immediately when native Session state is
  already `Starting`.

## Install

Download `Formation-Lap_0.9.0-preview.8_x64-setup.exe`, `SHA256SUMS.txt`,
`UNSIGNED-PREVIEW.txt`, and the provenance evidence from the official GitHub
prerelease. Verify the installer checksum and provenance before running it.
Expect Windows SmartScreen and UAC to identify the application and elevated
helper as an unknown publisher.

This is a per-user installer for 64-bit Windows 10 22H2 and Windows 11.
Organization policy may block installation or elevation of unsigned software.

## Trust and privacy

The installer has no Authenticode publisher signature. Its update bundle is
still signed with Formation Lap's Tauri updater key and is published with
checksums, an SPDX SBOM, dependency licenses/notices, and GitHub build
provenance. Profiles, settings, discovery results, logs, and recovery state
stay local.
