# Formation Lap 1.0.0

Formation Lap version one brings the complete local-first sim-racing Session
workflow to supported 64-bit Windows systems.

## Highlights

- Build reusable profiles from curated discovery or Manual Entry.
- Launch Supporting Applications in a controlled Startup Sequence and the
  Primary Sim last.
- Monitor readiness, retry or skip allowed failures, and close Session-owned
  Processes safely.
- Recover interrupted Sessions without assuming that a PID is still the same
  Process.
- Use explicit one-shot elevation where a selected application requires it.
- Export bounded local diagnostics without accounts, telemetry, or cloud
  storage.
- Choose system, light, or dark theme and use keyboard, scaling, or reduced
  motion preferences.
- Receive signed Formation Lap updates and notification-only third-party update
  advice without race-time interruptions.

## Install

Download `Formation-Lap_1.0.0_x64-setup.exe` from the official GitHub release.
Verify its Authenticode status and SHA-256 value against `SHA256SUMS.txt` before
running it. This is a per-user installer for 64-bit Windows 10 22H2 and Windows 11.

## Trust and privacy

All release executables are Authenticode-signed. The installer is additionally
signed for Formation Lap's updater and published with checksums, SPDX SBOM,
dependency licenses/notices, and GitHub provenance. Profiles, settings,
discovery results, logs, and recovery state stay local. Formation Lap has no
account, cloud sync, analytics, or telemetry.
