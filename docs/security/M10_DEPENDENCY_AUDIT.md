# M10 dependency audit

Date: 2026-07-24 · Target: `x86_64-pc-windows-msvc` · Version: `1.0.0`

## Result

No known npm production vulnerability or RustSec vulnerability was found.
Neither audit reported a high- or critical-severity finding.

## Commands

```powershell
pnpm.cmd audit --audit-level high --prod
cargo audit --file src-tauri/Cargo.lock
node scripts/release/generate-license-report.mjs `
  --root . `
  --output THIRD-PARTY-LICENSES.json `
  --notices THIRD-PARTY-NOTICES.txt
```

The npm audit reported `No known vulnerabilities found`. `cargo-audit 0.22.2`
loaded 1,169 RustSec advisories, scanned 485 locked crates, and exited
successfully with no vulnerability. It reported 17 advisory warnings:

- the unmaintained GTK3 `atk`, `gdk`, `gtk`, and related crates plus an unsound
  `glib` iterator implementation are non-Windows transitive Tauri dependencies
  and do not appear in the `x86_64-pc-windows-msvc` graph;
- `proc-macro-error` is unmaintained and does not appear in the Windows target
  graph; and
- five unmaintained `unic-*` crates remain in the Windows build graph through
  `urlpattern → tauri-utils`.

The warnings are not known vulnerabilities and do not cross Formation Lap's
runtime interfaces. The active `unic-*` chain is owned by the pinned current
Tauri stack; replacing it independently would fork or patch a
security-sensitive framework dependency. Recheck on every candidate and update
Tauri when an upstream replacement is available. A future vulnerability or
high/critical finding is release-blocking.

## License policy

The release generator resolves the locked production pnpm graph and the
Windows-target Rust graph, normalizes their exact SPDX expressions, and rejects
anything outside `scripts/release/allowed-licenses.json`. Its tests require both
ecosystems to appear, forbid denied expressions, and produce readable notices.
The official release publishes the JSON report, notices, and a separate SPDX
SBOM generated by pinned Syft.

This review does not treat dev-only packages as shipped application content.
GitHub dependency review still examines dependency changes in pull requests.
